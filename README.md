# tiny-fuzzy-finder

最小限・シンプルな Vim9 script 製の fuzzy finder。**依存なし**
「絞り込んで開くだけ」のポップアップ型ファインダー。

## 特徴

* Vim9 script のみ、外部依存なし
* 絞り込みは組み込み `matchfuzzy()` 任せ（自前ソートなし）
* `j`/`k` を含む入力はすべてクエリ。移動と入力が競合しない
* 状態はクエリ・候補・選択位置の3つのみ

## 使い方

```vim
:Tff    " cwd配下のファイルを列挙
```

| キー | 動作 |
| ---- | ---- |
| 印字可能文字 | クエリ入力（絞り込み） |
| `BS` | 1文字削除 |
| `↑` / `↓`, `C-p` / `C-n` | 移動 |
| `Enter` | 開く |
| `Esc` / `C-c` | 閉じる |

自動テスト: `vim -n -es --cmd "set rtp+=$PWD" -S test/check.vim < /dev/null`（成功時exit 0）
